- Ready-to-scan QR codes
- Direct `.mii` files
- HD / 60 FPS notes
- Texture pack pointers


## How to Get Started
1. Download v1.3.2.
2. Extract `Tomodachi-PC.zip`.
3. Pick 3DS or Switch.
4. Follow the emulator note in `files/emu/`.
5. Drop your dump, import Miis.

## Requirements
Windows 10/11. macOS / Linux if the emulator you pick runs there.
